# Market Storefront

Customer-facing Angular application for the Market Commerce Suite.

Current capabilities include catalog browsing, client-side search and sorting, API-driven category filtering, product details, reactive cart state, localStorage persistence, loading/error states, and a demo checkout flow.

The storefront currently uses Fake Store API and is not presented as a production payment or order-processing application.

From the repository root:

```bash
npm run install:storefront
npm run start:storefront
npm run test:storefront
```
